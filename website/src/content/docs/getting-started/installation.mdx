## Install

<Tabs>
<TabItem label="Homebrew">

```bash
brew install diktahq/tap/verikt
```

</TabItem>
<TabItem label="Install Script">

```bash
curl -fsSL https://verikt.dev/install.sh | bash
```

The script works on macOS and Linux, on amd64 and arm64. It resolves the latest release to a concrete tag, downloads that release's archive from GitHub, and checks it against the release's `checksums.txt` before installing. It refuses to install if the checksum entry is missing, the hash doesn't match, or neither `sha256sum` nor `shasum` is available. It installs to `/usr/local/bin` by default (with `sudo` if that directory isn't writable); set `VERIKT_INSTALL_DIR` to an absolute path to change that.

`VERIKT_VERSION` pins the release the script installs:

```bash
curl -fsSL https://verikt.dev/install.sh | VERIKT_VERSION=v0.2.0 bash
```

That pins the archive, not the script. `install.sh` itself is fetched live from verikt.dev each time, so piping it into `bash` runs whatever is published there at that moment. To review it first, download it, read it, then run it:

```bash
curl -fsSLo install.sh https://verikt.dev/install.sh
less install.sh
VERIKT_VERSION=v0.2.0 bash install.sh
```

The script doesn't touch your agent configuration. Pass `--setup` if you want it to run `verikt setup` right after installing:

```bash
curl -fsSL https://verikt.dev/install.sh | bash -s -- --setup
```

</TabItem>
<TabItem label="Pinned and verified">

Download the archive for one release and check it against that release's `checksums.txt` yourself. Everything you run is fixed to that version. Archives are named `verikt_<version>_<os>_<arch>.tar.gz`, for `darwin` or `linux` on `amd64` or `arm64`.

```bash
VERSION=v0.2.0
ARCHIVE="verikt_${VERSION#v}_darwin_arm64.tar.gz"
curl -fsSLO "https://github.com/diktahq/verikt/releases/download/${VERSION}/${ARCHIVE}"
curl -fsSLO "https://github.com/diktahq/verikt/releases/download/${VERSION}/checksums.txt"
grep "  ${ARCHIVE}$" checksums.txt | shasum -a 256 -c -   # or: sha256sum -c -
tar xzf "${ARCHIVE}" verikt && sudo mv verikt /usr/local/bin/
```

</TabItem>
<TabItem label="From Source">

```bash
git clone https://github.com/diktahq/verikt.git
cd verikt
go build -o verikt ./cmd/verikt
```

</TabItem>
</Tabs>

## Verify

```bash
verikt --version
```

## Shell Completions

<Tabs>
<TabItem label="Bash">

```bash
verikt completion bash > /etc/bash_completion.d/verikt
```

</TabItem>
<TabItem label="Zsh">

```bash
verikt completion zsh > "${fpath[1]}/_verikt"
```

</TabItem>
<TabItem label="Fish">

```bash
verikt completion fish > ~/.config/fish/completions/verikt.fish
```

</TabItem>
</Tabs>

<Aside type="tip">
After installing completions, restart your shell or run `source ~/.bashrc` (or equivalent) for them to take effect.
</Aside>
